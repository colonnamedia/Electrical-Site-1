# Keystone Current Electric — FireWorks website demo

A seven-page, mobile-first, fictional electrical contractor template for the FireWorks storefront.

## Pages

- `/` — hero, urgent safety preview, residential/commercial routing, and primary CTA
- `/services` — repairs, panels, lighting, EV charging, residential, and commercial routes
- `/electrical-repairs` — symptom-first repair content with safe guidance
- `/panel-upgrades` — capacity and panel-planning content
- `/lighting-ev` — lighting, controls, and EV charging routes
- `/service-areas` — verified-coverage scaffold
- `/request-service` — locally validating service request form

## Local checks

```bash
npm run check
npm run build
npx serve dist
```

Every identity, credential, review, business hour, service boundary, emergency statement, and availability claim is sample content. Forms validate locally and do not send, store, monitor, schedule, upload, book, or accept payment.
